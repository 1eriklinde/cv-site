Who reads this

Every page here is a static file, served from Cloudflare's edge without running any code. The one exception is a counter: each view adds one to a total and one to a tally for the country the edge resolved. That is the whole database — a key and a number, no row per visit, so it cannot say that any particular request happened.

$ cat views-by-country.txt

$ cat schema.sql

CREATE TABLE IF NOT EXISTS hits (
  k TEXT PRIMARY KEY,
  n INTEGER NOT NULL DEFAULT 0
);
what is stored
One row called total, and one row per country — cc:SE, cc:GB. Nothing else. No address, no user agent, no timestamp, no cookie, and no row for an individual visit.
where the country comes from
Cloudflare resolves it at the edge and hands it to the Worker, so your browser sends nothing it would not have sent anyway. A tally of one from a rarely-seen country is the most this can ever reveal.
what it costs
Nothing. Static assets are free and unlimited on the Workers free plan, and pages here are static assets — the Worker runs only for the counter call, and the free plan covers 100,000 of those a day.
the code
Forty lines, in src/index.js, with tests that fail if it ever reads a request header or stores anything identifying. How the site was built has the rest.
